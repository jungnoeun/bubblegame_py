# 🫧 Bubble Bobble

**Python과 Pygame을 활용하여 구현한 2D 플랫폼 게임**

## 📌 프로젝트 정보

개발 기간: 2026.10.01 ~ 2026.10.01

개발 언어: Python

라이브러리: Pygame

개발 형태: 2D 플랫폼 게임

## 🎮 게임 소개

플레이어가 발판을 이동하며 적을 거품으로 가두고 처치하는 게임.
- 방향키: 이동 및 점프
- SPACE: 거품 발사
- X: 거품 터뜨리기
- 적 처치 시 점수 획득
- 적과 충돌 시 게임 오버

## ✨ 주요 기능

- 플레이어 이동 및 점프
- 중력 및 발판 충돌 처리
- 적 자동 이동
- 거품 발사 및 적 포획
- 점수 시스템
- 게임 오버 처리

## 🛠️ 어려웠던 점

- 점프와 중력 구현
velocity_y와 중력 값을 활용하여 자연스러운 점프 구현

- 발판 충돌 처리
이전 프레임의 위치를 비교하여 발판을 안정적으로 착지하도록 구현

## 🚀 실행 방법
pip install pygame
python main.py
